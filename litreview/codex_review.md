# 독립 교차검토: ICL 기반 LLM symbolic regression

기준일: 2026-11-01. 검토 대상은 `papers_2025.md`, `papers_2026.md`의 본문 각 10편과 `paper_context.md`의 BAM-ICL 설명이다. 논문명·저자·최초 공개일은 각 항목에 연결한 arXiv abs 또는 DOI 원문을 직접 확인했다. arXiv의 연도는 최초 제출일(v1), DOI 논문은 온라인 출판일을 기준으로 한다. 방법과 수치는 연결한 원문 본문·표를 확인했으며, 모든 부록과 구현을 완전 감사했다는 뜻은 아니다. 점수는 3 = ICL/반복 피드백을 이용한 LLM 식 탐색이 중심, 2 = 관련 벤치마크·응용 또는 LLM과 SR의 간접 결합, 1 = 인접 연구, 0 = 주제와 무관이다. 반복 피드백이 곧 엄밀한 의미의 few-shot ICL임을 뜻하지는 않는다.

LLM-Feynman은 함수 작성 사실을 확인했지만 전체 구현에서 별도 수치 최적화가 없다는 주장은 **[UNVERIFIED]**다. 목록 전체의 부재를 입증하려면 버전별 본문뿐 아니라 실행 코드와 설정까지 점검해야 한다. 따라서 ‘직접 수치 생성이 드물다’는 관찰과 ‘특정 두 편만 확실하다’는 결론을 구별해야 한다.

[원문 §4.2와 부록](https://arxiv.org/html/2302.12170)은 이전 성공 식을 few-shot 문맥에 넣어 새 식과 수치 상수를 생성하고 적합도로 평가하는 SR 사례를 설명한다. 서술된 절차에는 별도 수치계수 최적화 단계가 보이지 않는다. **[UNVERIFIED]** 전체 코드와 모든 실험 설정에 최적화기가 전혀 없는지는 별도 확인 필요. 원자료를 직접 프롬프트에 입력하거나 MLIP 잔차를 다루는 연구라는 뜻은 아니다.

- **[UNVERIFIED] ‘MLIP 보정항을 ICL로 쓰는 선행연구는 없다’는 전 세계적 부재를 입증할 수 없다.** 본 조사에서는 동결된 MLIP의 에너지·힘 잔차를 LLM의 ICL로 closed-form 보정하고 계수를 refit하지 않는 동일 설계를 확인하지 못했다. 다만 인접 연구로 [Extraction of physicochemical laws by symbolic regression using a Bayesian information criterion](https://doi.org/10.1080/27660400.2024.2420658)은 신경망 포텐셜 관련 물성의 해석 가능한 SR 분석을, [Physically interpretable interatomic potentials via symbolic regression and reinforcement learning](https://www.nature.com/articles/s41524-025-01952-4)은 SR과 강화학습을 이용한 원자간 포텐셜을 다룬다. 특히 [A thermodynamic correction layer for machine learning interatomic potentials](https://arxiv.org/abs/2610.34551), Menon et al., v1 2026-10-25는 기반 GRACE를 재학습하지 않고 가산 보정층을 붙이는 직접적인 인접 선행이다. 선형 ACE를 수치 적합하며 LLM이나 ICL을 사용하지 않는다. 따라서 동결 MLIP 보정 자체의 최초성 주장은 성립하지 않는다. 이들을 동결 MLIP 잔차에 대한 LLM-ICL 보정과 동일시해서는 안 된다. 권장 표현은 ‘조사 범위에서 동일한 조합을 발견하지 못했다’이다.

## 추가할 후보 및 목록 상태

- **[Discovering Ordinary Differential Equations with LLM-Based Qualitative and Quantitative Evaluation](https://arxiv.org/abs/2605.07323)**, Sum Kyun Song, Bong Gyun Shin, Jae Yong Lee; v1 2026-05-08; arXiv:2605.07323. **서지 확인, 3/3.** DoLQ는 정성·정량 정보를 활용해 다중 에이전트가 ODE를 제안하고 반복 평가하며 수치 매개변수 최적화도 수행한다. 동역학적 closed-form 발견의 중요한 누락 후보다.
- **[LLM-Meta-SR](https://arxiv.org/abs/2505.18602)**, v1 2025-05-24; arXiv:2505.18602. **서지 확인, 2/3.** 메타 수준의 LLM 기반 SR 탐색과 연관된다. 다만 Claude의 2025년 목록에 이미 추가 후보로 언급되어 있으므로 목록 전체에서 누락된 것은 아니고 본문 10편에서 빠진 사례다. 직접 수치계수를 무보정 출력하는 설계로 단정하지 않는다.
- **[SR-LLM](https://doi.org/10.1073/pnas.2516995122)**, 2025년 온라인 공개. **DOI 확인, 2/3.** 검색증강 LLM과 SR을 결합하는 중요한 인접 후보로, 식 구조 탐색과 계수 보정을 구분해 비교할 가치가 있다. [UNVERIFIED] 목록에 이미 다른 제목으로 중복 기재되었는지 및 버전별 모든 계수 처리 세부사항.
- **[A-SR](https://arxiv.org/abs/2608.04872)**은 2026년 추가 후보에 이미 언급되어 있어 완전한 누락이 아니다. **[SymbolicLM](https://arxiv.org/abs/2609.33594)** 및 **[DIGEST](https://arxiv.org/abs/2610.33880)**도 제외·경계 사례로 이미 언급되어 있으므로, 관련 연구로 재검토하더라도 최초 발견 누락으로 표시하지 않는다.
